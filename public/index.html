«Камеры дома»: видеонаблюдение из обычного компьютера

Работает каждый день

Обычный компьютер с Windows 11 вместо видеорегистратора: записывает камеры, сам замечает людей и машины и показывает всё на телефоне.

Написал на Python сервер, который забирает потоки с камер в домашней сети, пишет их на диск и раздаёт через веб-интерфейс на React. Для настроек сделал отдельное окно программы с журналом событий и несколькими пользователями.

Самое интересное было дальше: как смотреть всё это с телефона, если провайдер не даёт белый IP, а VPN включать каждый раз лень. На пути встали три стены:

  • Белый IPего дома нет. Решение: домашний компьютер сам держит соединение с моим сервером в Москве, а тот открывает камеры по обычной ссылке.
  • Tailscaleс мобильного интернета не подключался. Решение: отказался от VPN, доступ идёт через тот же сервер с HTTPS.
  • Telegramуведомления туда не доходили. Решение: перевёл оповещения на «Алису» в Яндекс Станциях, ВКонтакте и бота в MAX.
  • РаспознаваниеОтличает людей и машины от веток и кошек — рамки на кадрах вверху настоящие.
  • Клип событияСохраняет 10 секунд до срабатывания и минуту после, чтобы было видно, откуда человек пришёл.
  • НочьюКамеры уходят в ИК-режим, распознавание продолжает работать.

rtspAtom: панель камер для компьютера без интернета

В разработке

Как поставить программу, если у компьютера нет интернета вообще, а операционная система — Astra Linux Special Edition «Смоленск»?

rtspAtom — панель для управления RTSP-камерами под Astra Linux SE 1.8. Привычное «apt install» тут не работает: каждую зависимость нужно найти, скачать заранее на другой машине и собрать в пакет, который встанет без единого обращения в сеть.

Это хорошая школа: начинаешь понимать, из чего на самом деле состоит программа и что она тянет за собой.

  • Отечественная ОСAstra Linux SE 1.8 «Смоленск».

Свой мессенджер на Matrix

Развёрнут

Переписка, которая не зависит ни от чьих блокировок и не лежит на чужих серверах.

Развернул собственный защищённый сервер Matrix — открытого протокола для обмена сообщениями. Сообщения шифруются на устройствах участников, а сам сервер стоит там, где решаю я.

Подключиться можно из любого клиента Matrix: на телефоне, компьютере или в браузере.

  • Сквозное шифрованиеСодержимое переписки видят только участники.
  • Свой серверДанные под собственным контролем.

Этот сайт

Вы на нём

Сообщение из формы внизу страницы приходит мне в MAX через секунду после отправки.

Сервер написан на чистом Python, без единой сторонней библиотеки. Он встал рядом с двумя другими сайтами на том же сервере и не задел их: HTTPS выдаёт Caddy, а каждый сайт живёт в своей папке.

Отдельное приключение — API MAX: он работает на сертификате Минцифры, которого нет в Ubuntu. Пришлось подключить его только для этого сайта, не трогая систему.

  • Без cookie и аналитикиШрифты и картинки отдаются с этого же сервера.
  • Защита от спамаЛовушка для ботов и ограничение частоты сообщений.
  • По 152-ФЗСогласие, политика, автоудаление сообщений через год.
